### 5. Hard Execution Safety Envelopes

- **Execution Concurrency**: Strictly sequential (`maxConcurrentInvocations = 1`). No parallel execution.
- **Request Ceilings**:
  - Global Request Ceiling: $14$ invocations maximum ($7 \text{ tasks} \times 2 \text{ candidates}$).
  - Per-Provider Ceiling: $7$ invocations maximum.
- **Retry Ceiling**: Maximum $1$ retry per task, allowed **only** on transient `HTTP 503 Service Unavailable`. Zero retries on $4\text{xx}$ errors, schema invalidity, or timeout.
- **Fallback Ceiling**: Maximum $1$ cross-provider fallback (DeepSeek $\to$ Gemini) upon retry exhaustion. Currently disabled (`CROSS_PROVIDER_FALLBACK_ENABLED = false`).
- **Monetary Budget Limits**:
  - Estimated Cost Ceiling: $25,000 \mu\text{USD}$ ($\$0.025$).

### 6. Kill-Switch Architecture (17 Event Categories)

Any occurrence of the following triggers results in immediate, fail-closed execution abort:
1. `PROVENANCE_MISMATCH`: Returned model identifier does not match expected model.
2. `MODEL_SUBSTITUTION_DETECTED`: Provider substituted a non-approved model variant.
3. `UNEXPECTED_MODEL_VERSION`: Version string mismatch.
4. `MALFORMED_USAGE_TELEMETRY`: Missing prompt/completion token metrics.
5. `CACHE_ARITHMETIC_INCONSISTENCY`: Cache hit + miss token counts do not sum to prompt tokens.
6. `REASONING_TOKEN_INCONSISTENCY`: Reasoning tokens exceed output bound or missing.
7. `REASONING_LEAKAGE_DETECTED`: Raw reasoning tokens exposed in public response.
8. `PRIVACY_CLASSIFICATION_VIOLATION`: Prohibited data classification detected in payload.
9. `TASK_SCOPE_VIOLATION`: Task type outside certified 7-task set.
10. `UNEXPECTED_RETRY_OR_FALLBACK`: Retry attempted on non-503 status.
11. `RECURSIVE_FALLBACK_ATTEMPTED`: Attempt to chain multiple fallbacks.
12. `NETWORK_DESTINATION_MISMATCH`: Outbound URL outside certified allowlist.
13. `COST_CEILING_BREACH`: Observed spend exceeds $50,000 \mu\text{USD}$.
14. `INVOCATION_LIMIT_BREACH`: Attempted call count exceeds 14.
15. `HUMAN_APPROVAL_INVALID`: Missing or invalid human approval envelope.
16. `UNAUTHORIZED_ENVIRONMENT`: Execution attempted in unapproved environment.
17. `UNEXPECTED_EXCEPTION`: Unhandled runtime exception in capability boundary.
